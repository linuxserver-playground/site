// Mods

Extend an image at start-up

A mod is a small layer applied when the container starts, set with the DOCKER_MODS environment variable. Universal mods work with every image; the rest target one.

How to use a mod

Add -e DOCKER_MODS=ghcr.io/linuxserver-playground/mods:universal-git to your run command, or an environment: entry in compose. Several mods are separated with|. The mod is pulled on every start, so pin a specific mod tag if you need reproducibility.

How to contribute a mod

Most of these mods were written by users who needed them. A mod is a Dockerfile, a few scripts and a mod.yml on its own branch of docker-mods: start from the template, test it against a real container, then open a pull request. An AI agent in our harness can write and test it with you, so you don't need to know the init system first.

  • Package install

    universal

    Installs any OS or Python packages named in INSTALL_PACKAGES and INSTALL_PIP_PACKAGES during container start, on Ubuntu and Alpine based images.

    2 settings
    • INSTALL_PACKAGES · OS packages to install, separated by `|` (e.g. `rsync|git|nginx`). Names must match the distro repo (pkgs.alpinelinux.org or packages.ubuntu.com); pin a version with `name=version` on apt or `name==version` on apk.
    • INSTALL_PIP_PACKAGES · Python packages to install with pip, separated by `|` (e.g. `apprise` or `apprise==1.10.0`). Setting it also installs python3-dev and pip, upgrades pip, setuptools and wheel, and adds the LinuxServer wheel index for the distro.
    DOCKER_MODS=ghcr.io/linuxserver-playground/mods:universal-package-install

Community project

Can't find the mod you need? Make it.

Most of these mods were written by users who needed them. A mod is a Dockerfile, a few scripts and a mod.yml; an AI agent in our harness writes it with you, applies it to a real container in your Docker and drafts the pull request.

Ask your agent

  • › Make a mod that installs <tool> into <image>, and test it.
  • › Make a universal mod that <what you need> in any image, and test it.
