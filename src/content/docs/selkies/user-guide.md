This guide is for people running the prebuilt Selkies based containers from LinuxServer.io: the Webtop desktops and the single application images like Chromium, Firefox, GIMP, or Steam.

You do not need to know anything about the internals to use these containers. If a page in this guide feels too deep, back up to the [Quickstart](/docs/selkies/quickstart/), it is genuinely enough for most people.

## Reading order

1. **[Quickstart](/docs/selkies/quickstart/)**: get a desktop or app streaming in one command, and learn the minimal command debugging philosophy.
2. **[Installation](/docs/selkies/installation/)**: docker run and compose in full, ports, volumes, PUID and PGID, and the options that actually matter.
3. **[GPU Acceleration](/docs/selkies/gpu/)**: Intel, AMD, and Nvidia passthrough, zero copy encoding, and multi GPU setups.
4. **[Using the Web Client](/docs/selkies/web-client/)**: the sidebar, clipboard, file transfer, gamepads, mobile controls, and session sharing.
5. **[Configuration Reference](/docs/selkies/configuration/)**: every environment variable in one place.
6. **[Available Apps and Desktops](/docs/selkies/apps/)**: the Webtop flavors and the full application catalog.
7. **[Installing Applications](/docs/selkies/installing-apps/)**: adding software inside a container with proot-apps or Docker mods.
8. **[Security and Hardening](/docs/selkies/security/)**: authentication, what the container can do, and lockdown variables for kiosk style deployments.
9. **[Reverse Proxy](/docs/selkies/reverse-proxy/)**: putting containers behind SWAG, Nginx, Traefik, or a subfolder.
10. **[WebRTC Transport](/docs/selkies/webrtc/)**: the opt in UDP transport, when it helps, and the STUN and TURN setup it needs.
11. **[Troubleshooting](/docs/selkies/troubleshooting/)**: the checklist to run before opening an issue.
