# Calibre-web - DriveThruRPG Metadata Provider

After installing, DriveThruRPG will be an option when pulling in metadata about a book.

In `calibre-web` docker arguments, set an environment variable `DOCKER_MODS=ghcr.io/linuxserver-playground/mods:calibre-web-dtrpg-metadata` to enable.

such as `DOCKER_MODS=ghcr.io/linuxserver-playground/mods:universal-calibre|ghcr.io/linuxserver-playground/mods:calibre-web-dtrpg-metadata`
